# Events

## Purpose
Groups event contracts or domain events used by the Moderation module.

## Files
- No direct files live in this folder; it primarily organizes child folders.

## Child Folders
- `CampaignReviewApproved`: The application event published through the outbox when a campaign review is approved.
- `CampaignReviewRejected`: The application event published through the outbox when a campaign review is rejected.
