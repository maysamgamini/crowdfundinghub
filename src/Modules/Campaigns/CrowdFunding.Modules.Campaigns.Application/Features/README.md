# Features

## Purpose
Groups the use cases of the Campaigns module by aggregate.

## Files
- No direct files live in this folder; it primarily organizes child folders.

## Child Folders
- `Campaigns`: Campaign lifecycle and funding-ledger commands, queries, and event handlers.
- `RewardTiers`: Reward-tier creation, slot reservation and release, queries, and handlers that release reservations when a payment fails or is refunded.
