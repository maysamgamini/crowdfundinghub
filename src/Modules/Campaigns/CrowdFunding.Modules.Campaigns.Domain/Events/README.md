# Events

## Purpose
Groups event contracts or domain events used by the Campaigns module.

## Files
- `CampaignCancelledDomainEvent.cs`: Domain event raised by an aggregate when business state changes.
- `CampaignCreatedDomainEvent.cs`: Domain event raised by an aggregate when business state changes.
- `CampaignFailedDomainEvent.cs`: Raised when a published campaign's deadline passes without reaching its goal.
- `CampaignPublishedDomainEvent.cs`: Domain event raised by an aggregate when business state changes.
- `CampaignSucceededDomainEvent.cs`: Raised when a published campaign reaches its goal by its deadline.

## Child Folders
- None.
