# Add Contribution To Campaign

## Purpose
The cross-module command Campaigns handles to credit a confirmed contribution to the campaign ledger, and its result (including `Credited`).

## Files
- `AddContributionToCampaignCommand.cs`: Command model dispatched through the application messaging pipeline.
- `AddContributionToCampaignResult.cs`: Result model returned by a handler or query operation.
