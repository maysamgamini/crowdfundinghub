# Commands

## Purpose
Groups contract-level commands exposed by the Pledges module.

## Files
- No direct files live in this folder; it primarily organizes child folders.

## Child Folders
- `ConfirmPledgePayment`: Implements the Confirm Pledge Payment command workflow for the Pledges module.
- `FailPledgePayment`: Implements the Fail Pledge Payment command workflow for the Pledges module.
- `MakePledge`: Implements the Make Pledge command workflow for the Pledges module.
