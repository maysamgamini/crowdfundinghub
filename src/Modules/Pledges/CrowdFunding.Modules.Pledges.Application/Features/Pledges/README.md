# Pledges

## Purpose
Contains source files related to Pledges.

## Files
- No direct files live in this folder; it primarily organizes child folders.

## Child Folders
- `Commands`: Groups contract-level commands exposed by the Pledges module.
- `Events`: Contains application event handlers that react to cross-module events relevant to the Pledges module.
- `Queries`: Groups contract-level queries exposed by the Pledges module.
