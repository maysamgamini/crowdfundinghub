# Crowd Funding Modules Pledges Domain

## Purpose
Contains the core domain model for the Pledges module, including invariants, events, and enums.

## Files
- `CrowdFunding.Modules.Pledges.Domain.csproj`: Project file that defines dependencies, target framework, and assembly references for this area.

## Child Folders
- `Aggregates`: Contains the aggregate roots that protect the core business rules for the Pledges module.
- `Enums`: Contains enum values that describe state transitions and classifications in the Pledges module.
- `Events`: Groups event contracts or domain events used by the Pledges module.
