# Features

## Purpose
Groups the Contributions use cases by feature area.

## Files
- No direct files live in this folder; it primarily organizes child folders.

## Child Folders
- `ActiveCampaigns`: Event handlers that replicate campaign state into the module's own `active_campaigns_cache`.
- `Contributions`: Contribution commands, queries, and the refund saga.
- `Metering`: Usage metering of confirmed pledges for OpenMeter.
