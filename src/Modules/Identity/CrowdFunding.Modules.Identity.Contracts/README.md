# Crowd Funding Modules Identity Contracts

## Purpose
Contains the integration-facing contract of the Identity module: authorization constants and claim names that other modules and the API host use. It defines no commands, queries, or events.

## Files
- `CrowdFunding.Modules.Identity.Contracts.csproj`: Project file that defines dependencies, target framework, and assembly references for this area.

## Child Folders
- `Authorization`: Contains shared authorization constants and claim metadata for the identity model.
