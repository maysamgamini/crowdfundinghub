# Contracts

## Purpose
Contains request and response contracts returned by the HTTP API.

## Files
- No direct files live in this folder; it primarily organizes child folders.

## Child Folders
- `CampaignUpdates`: Defines API contracts for campaign webhook subscription endpoints.
- `Campaigns`: Defines API contracts for campaign endpoints.
- `Common`: Defines shared API response shapes used by multiple endpoints.
- `Contributions`: Defines API contracts for contribution endpoints.
- `Identity`: Defines API contracts for authentication and user-management endpoints.
- `Moderation`: Defines API contracts for moderation endpoints.
- `Notifications`: Defines API contracts for backer notification preferences and unsubscribe endpoints.
- `RewardTiers`: Defines API contracts for reward-tier endpoints.
- `Webhooks`: Defines the payloads and acknowledgement of the inbound payment-gateway and media-analysis webhooks.
