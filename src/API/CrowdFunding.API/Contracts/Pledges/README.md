# Pledges

## Purpose
Defines API contracts for pledge endpoints.

## Files
- `ConfirmPledgePaymentRequest.cs`: Request contract consumed by an API endpoint.
- `ConfirmPledgePaymentResponse.cs`: Response contract returned by an API endpoint.
- `FailPledgePaymentRequest.cs`: Request contract consumed by an API endpoint.
- `FailPledgePaymentResponse.cs`: Response contract returned by an API endpoint.
- `ListPledgesResponse.cs`: Response contract returned by an API endpoint.
- `MakePledgeRequest.cs`: Request contract consumed by an API endpoint.
- `MakePledgeResponse.cs`: Response contract returned by an API endpoint.

## Child Folders
- None.
