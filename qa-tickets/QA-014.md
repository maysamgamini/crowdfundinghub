# QA-014: Outbox trace spans have no listener, so trace context is dropped

| | |
|---|---|
| Severity | P2 |
| Owner repo | crowdfunding |
| Status | Open |
| Evidence | A5-F15 (see `qa-tickets/evidence/`) |

## Problem

`ActivitySource("CrowdFunding.Outbox")` has no OpenTelemetry listener in `src`; hitechies-backend exports traces.

## Acceptance

Either an OTel listener and exporter are wired (opt-in) with a test that a span links to the request, or the docs stop claiming distributed tracing.
