# QA-003: With Messaging:Provider = RabbitMQ nothing consumes events, so no handler ever runs

| | |
|---|---|
| Severity | P1 |
| Owner repo | crowdfunding |
| Status | Open |
| Evidence | A2-F4, A1-F23 (see `qa-tickets/evidence/`) |

## Problem

`RabbitMqMessageBus` only publishes. Switching the provider silences every in-process handler, and the extracted Moderation service never creates reviews. The service README says otherwise.

## Acceptance

Either a consumer host exists and an integration test delivers an event through a broker, or the docs say plainly that the broker path is publish-only and name what is missing.
