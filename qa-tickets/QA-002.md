# QA-002: Extracted Moderation service lets any signed-in token read any review

| | |
|---|---|
| Severity | P1 |
| Owner repo | crowdfunding |
| Status | Fixed: handlers check the moderation permission in every host (ModerationReadAccessTests and the service integration test). |
| Evidence | A2-F3 (see `qa-tickets/evidence/`) |

## Problem

The service exposes the review read endpoint with `[Authorize]` and no policy, so any valid token reads any campaign's review.

## Acceptance

The read endpoint needs the moderation permission; a plain user token gets 403; a test in the Moderation service integration project proves it.
