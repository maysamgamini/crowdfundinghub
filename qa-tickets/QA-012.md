# QA-012: Audit trail covers one command and records refresh tokens in payloads

| | |
|---|---|
| Severity | P2 |
| Owner repo | crowdfunding |
| Status | Open |
| Evidence | A2-F13 (see `qa-tickets/evidence/`) |

## Problem

Only `CancelCampaign` is auditable. Audit payloads for refresh and logout include refresh tokens when an admin performs them.

## Acceptance

Sensitive fields are redacted; the list of audited commands is decided and documented; a test checks the redaction.
