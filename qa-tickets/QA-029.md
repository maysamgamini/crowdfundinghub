# QA-029: A message that crashes its worker is reclaimed forever (reclaim does not count as an attempt)

| | |
|---|---|
| Severity | P0 |
| Owner repo | hitechies-backend |
| Status | Open |
| Evidence | A5-F2, A5-F23 (see `qa-tickets/evidence/`) |

## Problem

The claim reclaims expired leases but never increments `Attempts`, and the processor has no dead-letter guard. There is no reclaim test.

## Acceptance

Port the attempt-counting reclaim and `OutboxReclaimE2ETests`; a poison message ends in the dead-letter table.
