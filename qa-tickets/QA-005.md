# QA-005: One-click unsubscribe is anonymous and appears to take any user id

| | |
|---|---|
| Severity | P1 |
| Owner repo | crowdfunding |
| Status | Open |
| Evidence | A2-F6 (see `qa-tickets/evidence/`) |

## Problem

`POST /api/notifications/unsubscribe` is `[AllowAnonymous]`. Verify how it identifies the user. If it trusts a user id in the request, anyone can unsubscribe anyone.

## Acceptance

The endpoint requires a signed, expiring token tied to the user (or a bearer token); a test shows a request naming another user's id is refused.
