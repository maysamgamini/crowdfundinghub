# QA-017: Closing fence at the deadline is not built

| | |
|---|---|
| Severity | P2 |
| Owner repo | crowdfunding |
| Status | Fixed as a simpler variant: late confirmations are rejected under the campaign lock and refunded (LateContributionTests, LateConfirmationRefundE2ETests); there is no ENDED state by design. |
| Evidence | A6-F5, A6-F10 (see `qa-tickets/evidence/`) |

## Problem

No database fence and no ENDED state; a late confirmation dead-letters without a refund. The close job can also strand a campaign between fence and decision.

## Acceptance

ENDED state, late confirmations refunded, and a recovery path for a stranded ENDED campaign, each with a test.
