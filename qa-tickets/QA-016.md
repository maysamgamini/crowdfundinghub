# QA-016: One live pledge per backer per campaign is not enforced

| | |
|---|---|
| Severity | P2 |
| Owner repo | crowdfunding |
| Status | Open |
| Evidence | A7-8, A6-F5 (see `qa-tickets/evidence/`) |

## Problem

The design's double-click protection has two halves. The idempotency key is built; the one-live-pledge rule is not.

## Acceptance

A partial unique index (or equivalent) on (backer, campaign) for live pledges, with a test for two simultaneous different-key requests.
