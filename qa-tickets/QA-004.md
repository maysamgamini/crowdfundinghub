# QA-004: docker-compose.microservices.yml monolith cannot reach its databases; base settings and compose disagree

| | |
|---|---|
| Severity | P1 |
| Owner repo | crowdfunding |
| Status | Open |
| Evidence | A2-F5, A2-F15 (see `qa-tickets/evidence/`) |

## Problem

The compose file runs the monolith as Development, so the localhost module connection strings in `appsettings.Development.json` override the compose settings. Separately, base `appsettings.json` and the standard compose file point at different databases.

## Acceptance

`docker compose -f docker-compose.microservices.yml up` brings up a monolith that migrates and serves a request; one table in the README states which settings file wins in each profile.
