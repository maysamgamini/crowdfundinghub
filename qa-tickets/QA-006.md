# QA-006: Moderation reviews have no concurrency token, so concurrent approve and reject can both succeed

| | |
|---|---|
| Severity | P2 |
| Owner repo | crowdfunding |
| Status | Open |
| Evidence | A2-F7 (see `qa-tickets/evidence/`) |

## Problem

`CampaignReview` has no xmin token and `ModerationTransactionExecutor` does not translate `DbUpdateConcurrencyException`, unlike Campaigns, Contributions and Identity.

## Acceptance

Concurrent approve and reject: exactly one wins, the other gets 409, and only one event reaches the outbox (integration test).
