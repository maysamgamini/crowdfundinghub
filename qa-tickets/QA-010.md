# QA-010: Outbox lease can expire before a batch ends; shutdown consumes retry attempts; lease is never renewed

| | |
|---|---|
| Severity | P2 |
| Owner repo | crowdfunding |
| Status | Partly fixed: expired leases are now reclaimed and a reclaim counts as an attempt; the lease is still not renewed for a handler that outlasts it, and shutdown still consumes an attempt. |
| Evidence | A2-F11, A5-F13 (see `qa-tickets/evidence/`) |

## Problem

The lease is 30 s and a sequential batch of 20 can outlast it, so in-flight rows can be reclaimed. A host shutdown counts as a failed attempt. Both repos share this.

## Acceptance

A slow-handler test shows a row is not reclaimed while its worker is alive (renewal or per-row lease), and shutdown does not consume an attempt.
