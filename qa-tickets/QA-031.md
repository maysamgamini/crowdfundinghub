# QA-031: Broker consumer commits the offset after three failures with only a log line (and on shutdown)

| | |
|---|---|
| Severity | P0 |
| Owner repo | hitechies-backend |
| Status | Open |
| Evidence | A5-F5 (see `qa-tickets/evidence/`) |

## Problem

Silent event loss when `Broker:Enabled` is true; cancelling during backoff commits an unprocessed message.

## Acceptance

Failed messages go to a dead-letter record before the offset is committed; shutdown does not commit; a test for each. Fix before enabling the broker anywhere.
