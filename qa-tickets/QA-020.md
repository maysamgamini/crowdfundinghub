# QA-020: Inbox is written after the handler and never pruned

| | |
|---|---|
| Severity | P3 |
| Owner repo | crowdfunding |
| Status | Partly fixed: inbox rows are pruned after 14 days (RetentionBackgroundService); the record is still written after the handler. |
| Evidence | A5-F8 (see `qa-tickets/evidence/`) |

## Problem

A crash between handler and record re-runs the handler once; inbox rows grow forever.

## Acceptance

Decide record-first in the same transaction or document the window; add a prune job with a test.
