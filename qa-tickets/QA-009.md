# QA-009: Refund saga can finish 'successfully' after a cancellation, losing the remaining refunds

| | |
|---|---|
| Severity | P2 |
| Owner repo | crowdfunding |
| Status | Open |
| Evidence | A2-F10 (see `qa-tickets/evidence/`) |

## Problem

The batch loop's `while (!IsCancellationRequested)` exits silently, and the event is then treated as handled.

## Acceptance

Cancellation mid-saga throws or leaves the work pending so redelivery finishes it; a test cancels after the first batch and proves the rest are refunded later.
